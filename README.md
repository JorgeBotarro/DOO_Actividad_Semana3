# Actividad Semana 3
Implementación de la App Llanquihue Tour.

## Integrantes
* Jorge Botarro Westerhout

## Estructura
* Model
  - Direccion: Dirección física de una persona.
  - Empleado: Persona con salario.
  - Persona: Información sobre una persona.
  - Rut: Número de identificación de una persona.
* App
  - Main: Punto de entrada de la App

## Instrucciones de uso
Este proyecto fue realizado en IntelliJ IDEA, pero puede ser ejecutado en cualquier IDE de Java.
basta con abrir la carpeta base en el IDE y ejecutar la clase Main.java
